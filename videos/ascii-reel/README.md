# ASCII Reel — секвенсор из ASCII-графики под озвучку

Вертикальное видео 1080×1920 (Reels, 30 fps) на [Remotion](https://www.remotion.dev/):
история из озвучки «играет» как лайвкод-секвенсор, и всё нарисовано символами.

- **Заголовок** — крупный текст, растеризованный в ASCII (` .:-=+*#%@`) с эффектом расшифровки.
- **story.js — live** — «живой код», который печатается синхронно с речью.
- **SEQ** — дорожки секвенсора (VOX, BEAT, GOOGLE, YANDEX, MONEY₽, RUSTORE, VK ID) меняют состояние по ходу рассказа.
- **Субтитры** — слово за словом, текущее слово подсвечено как выделение в терминале.
- Спектр и уровень голоса, CRT-сканлайны, свечение люминофора, глитч на «крэше».

## Обработка голоса (`tools/`)

1. `dfn3_enhance.py` — шумоподавление DeepFilterNet3 (ONNX + numpy-порт DSP из libDF), основной микрофон телефона.
2. `voice_master.py` — сжатие пауз (без резки слов), корректирующий EQ по LTAS, де-эссер, экспандер дыханий.
3. `finalize_voice.sh` — компрессия, темп ×1.07 без изменения высоты голоса, loudnorm −14 LUFS / −1.5 dBTP.
4. `asr.mjs` — Whisper (transformers.js, офлайн) с таймингами слов.
5. `build_transcript.py` — перенос таймингов через карту правок и темп, ручные правки текста → `src/data/transcript.ts`.
6. `audio_features.py` — уровень и 32 полосы спектра на каждый кадр → `src/data/audio-data.json`.

## Рендер

```bash
npm install
# положите обработанную озвучку в public/voice.wav
npx remotion render src/index.ts AsciiReel out/ascii-reel.mp4
```

Сцены, строки кода и состояния дорожек настраиваются в `src/story.ts` (привязка к индексам слов).
